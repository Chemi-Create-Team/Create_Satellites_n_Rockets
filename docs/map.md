# 衛星マップ

地上管制コンソールの「マップ」で開く画面です。ゲームは止まりません。共通制御コンピュータの「マップ」タブも同じ地球を描きます（[共通制御コンピュータ](control-computer.md)）。

## 画面の構成

| 場所 | 内容 |
| --- | --- |
| 上の帯 | 画面名、衛星の数、ゲーム内の日と時刻（琥珀色） |
| 左 | 衛星の一覧（番号・軌道の色の印・名前・緯度経度）。選んだ衛星は黄色で強調。表示しきれないときは右端に位置の帯 |
| 中央 | 雲のかかった立方体の地球と、衛星の点・軌道の円（青い枠） |
| 右 | 選んだ衛星の読み取り（コンソールの画面と同じ行）と、モードの色の帯 |
| 下 | 選んだ衛星の位置とブロック座標・高度、凡例（コンソール・選択中・操作の行と、軌道の色の行） |

画面の幅が380未満のときは、左右の一覧と読み取りを出さず、地球だけにします。

## 立方体の地球

| 項目 | 内容 |
| --- | --- |
| 形 | 完全な立方体。1面が8×8のマス（全6面で384マス）。陸地も海も平ら |
| 大きさ | 表示枠の幅の約4分の1（静止軌道の円が枠いっぱいになる大きさ） |
| 面の向き | 経度0度・経度90度東・北極などの方向にそれぞれ1面。北極が上の面、南極が下の面 |
| 海 | 青 |
| 陸地 | 緑（ところどころ茶）。緯度58度より高い陸地は茶 |
| 氷 | 緯度72度より高い所と、南緯60度より南の陸地は白 |
| マス目 | 1マスおきに少し暗くし、8×8の升目が見えるようにする |
| 陸地の形 | マスを6×6に分けて調べ、半分以上が陸ならそのマスは陸。Natural Earth 1:50m の陸地と湖（パブリックドメイン）から作った白黒画像 `textures/gui/land_mask.png`（512×256）を、起動後の初回表示で1回だけ読む |
| 光 | 左上から当たる固定の光で面ごとに明暗を付ける |
| 背景 | 星 |

### 雲

地表の上（マス0.25個分）に、地表と同じ8×8のマスの雲の層を重ねます。

| 項目 | 内容 |
| --- | --- |
| 見た目 | 白い半透明のマス。厚い雲ほど白く、透けにくい（2段階） |
| 量 | 空の約3分の1。赤道と中緯度に多く、亜熱帯と極に少ない |
| 動き | 東へ流れ、3日（72,000 tick）で地球を1周する。流れながら形も変わる。ゲーム時間（`getGameTime`）から決まり、保存しない。天気（雨・雷）とは関係しない |

## 衛星と軌道

衛星は点、軌道は円の線で描きます。軌道の円はどれも立方体の角（と雲の層）より外にあり、地球を突き抜けません。半径は見やすさのため縮尺どおりではありません。

| 軌道の段階（高度） | 円の半径（地球の1マスを1として） | 色 |
| --- | --- | --- |
| 0 低軌道（500 km） | 7.6（立方体の角のすぐ外） | 緑 |
| 1 高めの低軌道（2,000 km） | 9.2 | 青緑 |
| 2 中軌道（20,200 km） | 11.8 | 青 |
| 3 静止軌道（35,786 km） | 15（表示枠の端） | 紫 |

地球は1辺8マスなので、面の中心は中心から4、角は約6.9です。

- 衛星は縁の暗い四角の点です。通信衛星（中継衛星）はひし形の点です。
- 軌道は、衛星が今いる軌道面の1周を円の線で描きます（段階の色を暗くした線）。地球の自転で、円はゆっくり西へ回ります。
- 衛星から真下の地表まで、細い線を引きます。
- 静止軌道の半径の赤道上に、紫の破線の円（静止軌道帯）を常に描きます。傾斜0度の静止軌道の衛星はこの円の上に止まって見えます。
- 選んだ衛星は大きな黄色の点で、軌道の円・真下への線・真下の地点の印も黄色です。
- 放棄した衛星は灰色です。再突入中の衛星は橙で、燃え尽きる場所までの残りの経路を橙の線で描きます。高さは今の高度に合わせて地表まで下がります。
- コンソールの位置と選んだ衛星の真下の地点の印は、雲の上に出します。コンソールは緑の点です。
- 地球の裏にある点と線は地球に隠れます。地球の裏側にいる衛星の名前は出しません。
- 直近5分以内の警告（打ち上げ失敗・着陸失敗・再突入）は、地球の上端に赤い帯で点滅します。

## たくさんの衛星

数十機から百数十機の衛星を打ち上げても、見やすさと描画の軽さを保つように表示を変えます（`client/globe/Crowd`）。

| 条件 | 表示 |
| --- | --- |
| 同じ軌道（高度・傾斜角・昇交点が同じ。昇交点は1度単位、傾斜0度は昇交点を問わない）の衛星 | 軌道の円を1本だけ描く。放棄した衛星の円は別 |
| 違う軌道が40を超える | 選んだ衛星以外は円をやめ、各衛星の後ろに軌道の10分の1の短い弧を描く |
| 衛星が24機を超える | 真下への線は選んだ衛星だけ |
| 衛星が40機を超える | 点を小さくし、名前は選んだ衛星とマウスを重ねた衛星だけに出す |
| 名前どうしが重なる | 後から置く名前を出さない（選んだ衛星・マウスを重ねた衛星・手前の衛星の順に優先、最大24） |

150機（静止軌道40機、低軌道8面×10機、中軌道6面×4機など）で、地球と衛星の描画の計算は1フレーム約0.4ミリ秒、四角形は約2,000枚です。

## 操作

自分の通信衛星（OPならどれでも）がビーコンか点滅モードでコンソールの地平線の上にあると、画面下の[衛星写真](satellite-relay.md#衛星写真)ボタンを使えます。写真にはコンソール周辺4,096×4,096ブロックを表示します。

マウスをドラッグすると地球が回ります。最初はコンソールの上空（緯度は±40度まで）から見ています。

- 衛星の点をクリックすると（ドラッグせずに離すと）、その衛星をコンソールで選びます。近くに点が無ければ何もしません。地球の裏の点は、手前に近い点が無いときだけ選べます。
- 左の一覧の行をクリックしても選べます。マウスホイールで一覧を3行ずつ動かせます（選択が変わると選んだ衛星の周りへ戻ります）。
- マウスを重ねた衛星は名前を出します。
- 選ぶことはコンソールの前へ・次へボタンと同じで、持ち主でなくてもできます。コンソールから8ブロック以内で、存在する衛星だけです（通信 `console_select`）。
