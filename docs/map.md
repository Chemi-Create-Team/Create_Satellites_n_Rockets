# 衛星マップ

地上管制コンソールの「マップ」で開く画面です。ゲームは止まりません。共通制御コンピュータの「マップ」タブも同じ地球を描きます（[共通制御コンピュータ](control-computer.md)）。

## 画面の構成

| 場所 | 内容 |
| --- | --- |
| 上の帯 | 画面名、衛星の数、ゲーム内の日と時刻（琥珀色） |
| 左 | 衛星の一覧（番号・名前・緯度経度）。選んだ衛星は黄色で強調 |
| 中央 | 立方体の地球と衛星（青い枠） |
| 右 | 選んだ衛星の読み取り（コンソールの画面と同じ行）と、モードの色の帯 |
| 下 | 選んだ衛星の位置とブロック座標・高度、凡例 |

画面の幅が380未満のときは、左右の一覧と読み取りを出さず、地球だけにします。

## 立方体の地球

| 項目 | 内容 |
| --- | --- |
| 形 | 半径28個の立方体を積んだ球 |
| 海 | 青 |
| 陸地 | 海より1個高い。緑（ところどころ茶） |
| 極 | 緯度72度より高い所は白 |
| 陸地の形 | Natural Earth 1:50m の陸地と湖（パブリックドメイン）から作った白黒画像 `textures/gui/land_mask.png`（512×256）を、起動後の初回表示で1回だけ読む |
| 光 | 左上から当たる固定の光で面ごとに明暗を付ける |
| 背景 | 星 |

## 衛星の表示

- 衛星は、立方体の本体と2枚の太陽電池パネルの小さな機体です。真下の地点の上、軌道の段階に応じた高さに描きます。
- 高さは見やすさのため縮尺どおりではありません（地球の半径に対し、段階0から順に1.16・1.3・1.52・1.75倍）。
- 選んだ衛星は大きく黄色で描き、軌道を1周先まで黄色の点で、少し前までを暗い点で描きます。ほかの衛星の軌道は淡い点です。地球が回るので、軌道は閉じた輪になりません。
- 放棄した衛星は灰色、再突入中の衛星は橙で、燃え尽きる場所までの残りの経路を橙の点で描きます。高さは今の高度に合わせて地表まで下がります。
- コンソールの位置は、地表の緑の点です。
- 直近5分以内の警告（打ち上げ失敗・再突入）は、地球の上端に赤い帯で点滅します。
- 地球の裏側にいる衛星の名前は出しません。

## 操作

通信衛星を選ぶと画面下の[衛星写真](satellite-relay.md#衛星写真)ボタンを使えます。

マウスをドラッグすると地球が回ります。最初はコンソールの上空（緯度は±40度まで）から見ています。
