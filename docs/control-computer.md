# 共通制御コンピュータ（Create: Frontier Science）

[Create: Frontier Science](https://github.com/Chemi-Create-Team/Create-Frontier-Science)（CFS）0.3.32以降が入っていると、地上管制コンソールは共通制御コンピュータの「追加アプリ」の**人工衛星**としても使えます。導入は任意です。CFSがないか、キャンバスAPIのない古いCFSでは、何も追加しません。CFS 0.3.38以降（アプリAPI v3）では、マップの衛星をクリックで選べ、表示状態が再起動後も残ります。

## 開き方

CFSの共通制御コンピュータに液晶ディスプレイボードをつなぎ、**追加アプリ**から**人工衛星**を選びます。アプリはウィンドウ表示です。地上管制コンソールのブロックは要りません。

## 制御タブ

- 選んだ衛星の名前（積荷があれば種類も、放棄・再突入中ならその状態も）。
- 読み取り9項目：何機目か・持ち主・位置・真下のブロック座標・高度・傾斜角・周期・モード・ボードから見えるか（仰角と方位）。数値は琥珀色、モードはモードの色、見えるときは緑。
- ボタン（5列×2段）：前へ・次へ・モード・高度 -／+・傾斜角 -／+・再突入・放棄。ダイヤルの端や、衛星が1機しかないときの前へ・次へ、再突入中の衛星の操作、放棄した衛星の再突入以外は無効（灰色）になります。再突入と放棄は、押したボタンだけが1回目で「再突入を確定」「放棄を確定」に変わり、10秒以内に同じボタンをもう一度押すと実行します。もう一方のボタンを押すと、そちらの確認に切り替わります。コンピュータから再突入させた衛星は、ディスプレイボードの上空で火球になります。
- 直近5分以内の警告（打ち上げ失敗・再突入）があれば、タブの右に衛星数の代わりに点滅して出ます。

## マップタブ

- [衛星マップ](map.md)と同じ雲のかかった立方体の地球と、衛星の点・軌道の円を、ボードの上空から見た向きで描きます。
- ボタン：前へ・次へ・左へ回す・右へ回す（1回45度）。
- 衛星がたくさんあるときの表示は衛星マップと同じです（[たくさんの衛星](map.md#たくさんの衛星)）。名前は重ならないものだけ（最大16）、40機を超えると選んだ衛星と照準を合わせた衛星だけに出します。
- 照準を合わせた衛星の点は名前を出します。
- **CFS 0.3.38以降**：地球の上の衛星の点を右クリックすると、その衛星を選びます（前へ・次へと同じく、衛星の持ち主でなくてもできます）。サーバーはCFSのアプリAPI v3からキャンバスの大きさを受け取り、描画と同じ計算（`CfsLayout.mapView`・`Spots`）で、照準から一番近い点（地球の1マス強の範囲、手前の点を優先）を選びます。点のない所をクリックしても何も起きません。それより古いCFSでは前へ・次へで選びます。
- 下に、選んだ衛星の位置とブロック座標・高度を表示します。

## 権限と保存

- 操作には、CFSが確かめるコンピュータの権限に加え、衛星の持ち主かOPであることが必要です。
- 表示中のタブ・地球の向き・選んだ衛星・カバー（確認待ちのボタンとその時刻）は、**CFS 0.3.38以降**では液晶ディスプレイボードごとに、CFSがボードと一緒にワールドへ保存します（アプリAPI v3の保存状態）。サーバーを再起動しても残り、同じコンピュータにつないだ液晶はそれぞれ別の表示を持てます。ボードを別のコンピュータにつなぎ直すと消えます。それより古いCFSでは、コンピュータごとにサーバーのメモリに持ち、再起動で制御タブ・最初の衛星に戻ります（1日使われないと忘れます）。
- サーバーが送るのはタブ・向き・選んだ衛星・カバーの期限だけで、衛星の位置と時刻はクライアントが自分で計算します。
