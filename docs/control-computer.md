# 共通制御コンピュータ（Create: Frontier Science）

[Create: Frontier Science](https://github.com/Chemi-Create-Team/Create-Frontier-Science)（CFS）0.3.26以降が入っていると、地上管制コンソールは共通制御コンピュータの「追加アプリ」の**人工衛星**としても使えます。導入は任意です。CFSがないか、キャンバスAPIのない古いCFSでは、何も追加しません。

## 開き方

CFSの共通制御コンピュータに液晶ディスプレイボードをつなぎ、**追加アプリ**から**人工衛星**を選びます。アプリはウィンドウ表示です。地上管制コンソールのブロックは要りません。

## 制御タブ

- 選んだ衛星の名前（積荷があれば種類も）。
- 読み取り9項目：何機目か・持ち主・位置・真下のブロック座標・高度・傾斜角・周期・モード・ボードから見えるか（仰角と方位）。数値は琥珀色、モードはモードの色、見えるときは緑。
- ボタン：前へ・次へ・モード・高度 -／+・傾斜角 -／+・軌道離脱。ダイヤルの端や、衛星が1機しかないときの前へ・次へは無効（灰色）になります。軌道離脱は1回目で「離脱を確定」に変わり、10秒以内の2回目で取り除きます。

## マップタブ

- [衛星マップ](map.md)と同じ立方体の地球と衛星を、ボードの上空から見た向きで描きます。
- ボタン：前へ・次へ・左へ回す・右へ回す（1回45度）。
- 下に、選んだ衛星の位置とブロック座標・高度を表示します。

## 権限と保存

- 操作には、CFSが確かめるコンピュータの権限に加え、衛星の持ち主かOPであることが必要です。
- 表示中のタブ・地球の向き・選んだ衛星・軌道離脱のカバーは、コンピュータごとにサーバーのメモリに持ちます。サーバーを再起動すると、制御タブ・最初の衛星に戻ります。
- サーバーが送るのはタブ・向き・選んだ衛星・カバーの期限だけで、衛星の位置と時刻はクライアントが自分で計算します。
