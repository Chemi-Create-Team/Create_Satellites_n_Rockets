# 共通制御コンピュータ（Create: Frontier Science）

[Create: Frontier Science](https://github.com/Chemi-Create-Team/Create-Frontier-Science)（CFS）0.3.32以降が入っていると、地上管制コンソールは共通制御コンピュータの「追加アプリ」の**人工衛星**としても使えます。導入は任意です。CFSがないか、キャンバスAPIのない古いCFSでは、何も追加しません。

## 開き方

CFSの共通制御コンピュータに液晶ディスプレイボードをつなぎ、**追加アプリ**から**人工衛星**を選びます。アプリはウィンドウ表示です。地上管制コンソールのブロックは要りません。

## 制御タブ

- 選んだ衛星の名前（積荷があれば種類も、放棄・再突入中ならその状態も）。
- 読み取り9項目：何機目か・持ち主・位置・真下のブロック座標・高度・傾斜角・周期・モード・ボードから見えるか（仰角と方位）。数値は琥珀色、モードはモードの色、見えるときは緑。
- ボタン（5列×2段）：前へ・次へ・モード・高度 -／+・傾斜角 -／+・再突入・放棄。ダイヤルの端や、衛星が1機しかないときの前へ・次へ、再突入中の衛星の操作、放棄した衛星の再突入以外は無効（灰色）になります。再突入と放棄は1回目で「再突入を確定」「放棄を確定」に変わり、10秒以内の2回目で実行します。コンピュータから再突入させた衛星は、ディスプレイボードの上空で火球になります。
- 直近5分以内の警告（打ち上げ失敗・再突入）があれば、タブの右に衛星数の代わりに点滅して出ます。

## マップタブ

- [衛星マップ](map.md)と同じ立方体の地球と衛星を、ボードの上空から見た向きで描きます。
- ボタン：前へ・次へ・左へ回す・右へ回す（1回45度）。
- 下に、選んだ衛星の位置とブロック座標・高度を表示します。

## 権限と保存

- 操作には、CFSが確かめるコンピュータの権限に加え、衛星の持ち主かOPであることが必要です。
- 表示中のタブ・地球の向き・選んだ衛星・カバーは、コンピュータごとにサーバーのメモリに持ちます。サーバーを再起動すると、制御タブ・最初の衛星に戻ります。
- サーバーが送るのはタブ・向き・選んだ衛星・カバーの期限だけで、衛星の位置と時刻はクライアントが自分で計算します。
