# 地上管制コンソール（`ground_console`）

衛星を選んで読み、持ち主が操作するブロックです。画面は向こう側にあり、操作部は上面です。画面が自分と反対向きになるように置き、上面のボタンを空の手でクリックします。

製法（作業台）：上段に真鍮板3、中段に電子管・精密機構・電子管、下段に真鍮ケーシング3。

## ボタン

| ボタン | 操作 | 権限 |
| --- | --- | --- |
| 前へ・次へ | 選ぶ衛星を切り替える（打ち上げ順、端で反対側へ回る） | 誰でも |
| マップ | [衛星マップ](map.md)を開く。自分の通信衛星を選んでいる場合はマップから[写真を撮る](satellite-relay.md#衛星写真)（写真は持ち主・OP） | 誰でも |
| モード | 待機 → ビーコン → 点滅 → 待機 | 持ち主・OP |
| 高度ダイヤル | 左半分で1段下げ、右半分で1段上げる（段階0〜3） | 持ち主・OP |
| 軌道傾斜角ダイヤル | 左半分で1段下げ、右半分で1段上げる（0・30・55・90度） | 持ち主・OP |
| 再突入（赤いボタン） | 1回目でカバーが開き、200 tick（10秒）以内の2回目で、衛星をこのコンソールの上空へ再突入させる（[放棄と再突入](orbit.md#放棄と再突入)） | 持ち主・OP（放棄した衛星はOPだけ） |
| 放棄（手前右隅の黄黒のボタン） | カバーが開いている間だけ効き、衛星を放棄する。カバーが閉じていれば「先にカバーを開ける」と表示する | 持ち主・OP |

持ち主でもOPでもない人が操作すると「他人の衛星は操作できない」と表示し、何も変えません。放棄した衛星は、持ち主でも操作できません（OPは再突入だけできます）。再突入中の衛星は、前へ・次へ・マップ以外を受け付けません。カバーが開いている間は、放棄ボタンが点滅します。ダイヤルの上には、今の段階まで点灯する4つの目盛りがあります。モードのボタンはモードの色で光ります。

## 画面

選んだ衛星について、次の行を表示します。衛星がなければ「衛星なし」と「発射台から打ち上げよう」です。

1. 名前と、何機目か（例 `2/3`）
2. 状態（ふつうの衛星では出ない）：「放棄 - 安定軌道」「放棄 - 約N日後に落下」（灰色）、「再突入中 - N秒後に燃え尽きる」「火球 - 残りN秒」（赤）
3. 積荷（他のMODの衛星だけ。[ペイロードAPI](api.md)）
4. 緯度・経度
5. 真下のブロック座標（X・Z）
6. 高度（再突入中は落ちていく今の高度）・傾斜角・周期（分）
7. モード
8. コンソールから見えるか（見えれば仰角と方位）
9. 持ち主

直近5分以内に打ち上げの失敗か再突入の開始があれば、いちばん上に警告の行が点滅します（[警告](orbit.md#警告)）。長い行は画面幅に収まるよう縮め、8行を超えるときは全体を縮めます。

## ディスプレイリンク

コンソールを情報源にしたディスプレイリンクは、選んだ衛星の「名前 緯度 経度 高度」を1行で表示します（20 tickごと、ラベル付き可）。

## 保存

選んだ衛星とカバーの状態は、コンソールごとに保存します。
